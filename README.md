# Daily Calorie Tracker

A beginner-friendly Python command-line application that helps users record their daily meals, calculate calorie intake, and compare their total against a daily calorie goal.

## Overview

This was one of my first Python lab projects, created as part of my journey into programming.

The program takes food items and their calorie values as input, stores them in Python lists, calculates the total and average calories, and checks whether the user's daily intake exceeds their target.

## Features

- Record multiple meals and snacks
- Store food names and calorie values using Python lists
- Calculate total calorie intake
- Calculate average calories per food item
- Compare total intake against a daily calorie goal
- Display a simple food and calorie summary
- Show a message based on the daily goal

## Technologies Used

- Python 3
- Python lists
- Loops (`for`)
- Conditional statements (`if/else`)
- User input and output
- Basic arithmetic operations

## Getting Started

### Requirements

- Python 3 installed on your computer

No external Python libraries are required.

### Run the Project

Clone the repository:

```bash
git clone https://github.com/Svn8efx/daily-calorie-tracker-python.git
```

Open the project folder:

```bash
cd daily-calorie-tracker-python
```

Run the Python program:

```bash
python "calories tracker.py"
```

## How It Works

1. Enter the number of meals or snacks consumed.
2. Enter each food item's name.
3. Enter the calorie value for each item.
4. Enter your daily calorie goal.
5. View the food summary, total calories, average calories, and goal comparison.
